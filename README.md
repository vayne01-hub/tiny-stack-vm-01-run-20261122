# Tiny Stack VM Interpreter

A from-scratch interpreter for the tiny-stack-vm-01 bytecode ISA: a stack machine with 32-bit wrapping arithmetic, byte-addressed memory, structured traps, and byte-exact stdout. Written in TypeScript, Node 22 standard library only, no dependencies.

## Run

The grader runs `node main.ts` with the program and input under `$MAKEFUN_INPUT_DIR`; output bytes go to `$MAKEFUN_OUTPUT_DIR`.
